# Rivis Terms of Use

<!-- RIVIS-PLACEHOLDER-TERMS: a release build replaces this file with the organisation's own terms. -->

This copy of Rivis was built from the source repository and carries placeholder terms.

Rivis captures, decrypts and can change network traffic. Use it only on traffic you are allowed to inspect, only for
the purposes your organisation approves, and keep what it records on your own workstation.

By typing your name you confirm that you have read these terms and will follow them. If you do not agree, Rivis does
not run.
